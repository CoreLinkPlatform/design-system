# Core Platform Typography

## Primary Typeface

### Latin / General UI

Noto Sans

Usage:
- application UI
- dashboards
- documentation
- system text

### Persian / Arabic UI

Noto Sans Arabic

Usage:
- Persian content
- RTL interfaces
- localized applications

## Display Typeface

Handjet

Usage is limited to:
- large metrics
- special brand moments
- experimental display areas

Do not use Handjet for normal UI text.

## Rules

- Typography must be consumed through design tokens.
- Products must not define independent font stacks.
- RTL and LTR layouts must share semantic typography tokens.
