# Core Platform Brand Guide

## Brand Architecture

Core Platform is the foundation layer for connected systems.

```
Core Platform

├── Core Link
│   Connectivity layer
│
├── Core Signal
│   Intelligence and decision layer
│
└── Core Console
    Control and operation layer
```

## Typography

Primary typography:

- Noto Sans
- Noto Sans Arabic

Special display usage:

- Handjet

Handjet is limited to brand moments, key metrics, and expressive areas.

## Iconography

Primary icon system:

Phosphor Icons

Preferred style:

- Duotone

Icons must be consistent across light and dark themes.

## Shape Language

Components use a consistent radius scale.

Avoid sharp and inconsistent UI elements.

Cards, panels, dialogs and controls must follow shared tokens.

## Color Philosophy

Applications consume Core Palette tokens.

No product should define independent colors.

Semantic colors:

- Primary
- Secondary
- Success
- Warning
- Danger
- Neutral

## Theme

Default:

Light mode

Supported:

Dark mode

Both themes share identical semantic tokens and component behavior.
