# Core Console Migration Plan

## Phase 0 - Audit

Review the existing Console:

- Existing screens
- Components
- API dependencies
- UX problems

## Phase 1 - Foundation

Implement:

- Design tokens
- App shell
- Navigation
- Theme system
- Core components

## Phase 2 - Resources

Migrate:

- Devices
- Connectors
- Providers
- Integrations

## Phase 3 - Intelligence

Add:

- Signals
- Rules
- Evaluations
- Decisions

## Phase 4 - Operations

Add:

- Monitoring
- Logs
- Alerts
- Audit

## Definition of Done

Console is complete when:

- All pages consume Design System components
- No hardcoded visual values exist
- Resources share consistent patterns
- Light and dark themes are supported
- Multi-tenancy is considered
- Core Link and Core Signal integration is supported
