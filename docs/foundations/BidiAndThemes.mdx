Direction and theme are independent runtime dimensions. Components must remain usable in Persian RTL and English LTR, in light and dark themes.

## Runtime contract

- Set the content language with `lang="fa"` or `lang="en"`.
- Set direction at the application boundary with `dir="rtl"` or `dir="ltr"`.
- Use logical properties such as `margin-inline-start`; do not mirror with ad-hoc transforms.
- Select application themes with `data-theme="light"` or `data-theme="dark"`.
- Use the Storybook toolbar for component stories and the side-by-side samples above for docs-only pages.
- Never encode theme colors inside a component.
- Focus remains a 2px Core Blue ring with a 2px offset in every mode.
