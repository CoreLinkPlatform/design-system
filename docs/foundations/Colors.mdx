## Semantic layers

| Layer | Examples | Rule |
| --- | --- | --- |
| Surface | page, default, subtle, raised | Establish depth and grouping |
| Text | primary, secondary, muted, disabled | Express hierarchy, not decoration |
| Border | default, strong | Separate without competing with content |
| Action | primary, danger | Reserve for interactive intent |
| Status | success, warning, danger, info, offline, degraded, unknown | Keep operational meaning stable |

Light and dark values are exported by the same token names. Primary action text intentionally uses `text.onPrimary` rather than assumed white, preserving contrast on Core Blue.
