# Brand foundation

Core is an industrial, data-first product family. The visual language should feel precise, calm and operational across Core Console, Core Link and Core Signal.

## Runtime expression

Core Cyan, Blue and Violet are brand anchors—not permission to hardcode color. Product UI consumes semantic action, surface, text, border and status tokens. Handjet is a sparse display accent; it is not body copy. RTL is a first-class mode rather than a post-build mirror.

## Ownership boundary

Canonical meaning is owned by `CoreLinkPlatform/product-planning/design`. This package implements, tests and documents the accepted contract.
