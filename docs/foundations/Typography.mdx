The runtime selects type by content language while preserving one hierarchy.

| Role | Runtime family | Usage |
| --- | --- | --- |
| Persian/Arabic UI | Noto Sans Arabic Variable | Body, labels and headings for Arabic script |
| Latin UI | Noto Sans Variable | Body, labels and headings for Latin script |
| Code/data | JetBrains Mono | Identifiers, code and aligned technical values |
| Display accent | Handjet Variable | Sparse branded or industrial display moments only |

Do not force the Arabic family on English content or use Handjet for dense UI. Set `lang` and `dir` at a meaningful content boundary.
