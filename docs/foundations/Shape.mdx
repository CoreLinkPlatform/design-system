## Control heights

| Size | Value | Intended use |
| --- | ---: | --- |
| Small | 36px | Dense secondary tools |
| Medium | 44px | Default interaction target |
| Large | 52px | Prominent or touch-heavy actions |

Arbitrary radii and pill shapes are not part of the accepted runtime slice.
