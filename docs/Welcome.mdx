## Start here

1. Review **Foundations / Source and revision** before changing any semantic value.
2. Use the theme toolbar and the Persian/English examples while reviewing components.
3. Consume exported tokens and components; avoid hardcoded product styles.
4. Propose new shared behavior with consumer evidence and accessibility criteria.

## Product principles

- Token-driven implementation
- Persian RTL and English LTR as equal runtime modes
- Accessibility as a release condition
- Industrial clarity over decorative complexity
- Canonical decisions in Product Planning; implementation evidence in this repository
