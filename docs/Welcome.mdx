# Core Platform Design System

## Building consistent industrial interfaces

Core Design System is the shared UI foundation for:

- Core Console
- Core Link
- Core Signal

## Principles

### Token driven

All interfaces are built from shared design tokens.

### RTL first

Persian and Arabic interfaces are first-class citizens.

### Accessible

Components follow modern accessibility practices.
